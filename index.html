Conectar con la base maestra

Pega la URL de la aplicación web de Google Apps Script incluida en el paquete. El tablero consulta la fuente al abrirse, al pulsar «Actualizar datos» y cada 60 segundos mientras está visible. Esta configuración se guarda solo en este navegador.

Para todos los visitantes de GitHub Pages, coloca esa URL en CONFIG.endpoint dentro de este HTML. La vista inicial contiene una copia agregada de abril de 2026; solo la conexión activa refleja cambios nuevos.

El porcentaje global se calcula con la suma de días asistidos dividida por la suma de días de clases. Al seleccionar varios meses, el número de registros no equivale a estudiantes únicos.
